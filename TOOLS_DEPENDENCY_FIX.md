## Root Cause
The `hermes_tools` module was **not installed** in the system Python environment. It's normally auto-generated by Hermes Agent for use with AIAgent scripts, but the Gematria tools were trying to import it directly using `from hermes_tools import ...`.

## Solution Implemented
Created `/home/avalonas/.hermes/hermes_tools.py` - a stub module providing direct RPC access to Hermes tools:
- ✅ `web_search()` - Search web for information
- ✅ `web_extract()` - Extract page content in markdown  
- ✅ `read_file()` - Read files with pagination
- ✅ `write_file()` - Write/overwrite files
- ✅ `search_files()` - Fuzzy file content search
- ✅ `patch()` - Targeted find-and-replace edits
- ✅ `terminal()` - Execute shell commands

## How to Use
Scripts already add the path correctly:
```python
import sys

sys.path.insert(0, str(Path.home() / ".hermes"))
from hermes_tools import web_search, terminal, read_file
```

Or run with PYTHONPATH set:
```bash
export PYTHONPATH="/home/avalonas/.hermes:$PYTHONPATH"
python scripts/myscript.py
```
