═══════════════════════════════════════════════════════
COMMAND EXAMPLES FOR EACH SCENE
═══════════════════════════════════════════════════════

# Generate just fireflies for a specific trail:
python3 animation_generator.py --scene fireflies

# Generate all scenes in auto mode:
python3 animation_generator.py --auto

# Use NES 8-bit style for retro look:
python3 animation_generator.py --preset nes

# Combine with overnight runner for automation:
python3 overnight_runner_local.py \
    --generate-art \
    --scene fireflies

═══════════════════════════════════════════════════════
OUTPUT FORMAT DETAILS
═══════════════════════════════════════════════════════

File Format: MP4 (H.264/AAC)
Resolution: Scaled to fit source image (max 720px width)
Bitrate: Adaptive, ~250kbps target
Frame Rate: Variable per scene (10-15fps)

Example output paths:
- ./output/art/animations/trail_correlation_fireflies.mp4
